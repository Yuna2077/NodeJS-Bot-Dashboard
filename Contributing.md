# Pull Request
Pull request's written by LLM's will automatically be declined no matter the code, so please make sure that you put in the effort to write the code.
Keep pull requests small and focused. A bug, fix or one self-contained change is easy to review unlike a large code drop.
If you plan a big feature you can discuss it in our [discord](https://discord.gg/sPQFM9Rj33) before writting the code.
